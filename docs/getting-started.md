# Getting Started

## Prerequisites
- Python 3.11+
- Git
- A GitHub account
- D: drive for storage (critical rule for this project)

## Installation

```bash
# Clone the repository
git clone https://github.com/smkalpanaopenclaw-a11y/smk-platform.git
cd smk-platform

# Install dependencies
make install

# Run tests
make test

# Start development server
make dev
```

## Project Goals
1. Build AI agents on ourselves first
2. Package successful solutions for clients
3. Focus on businesses with zero digital footprint

## D: Drive Rule
All AI work, data storage, downloads, and agent installations MUST go on the D: drive. This keeps the C: drive free and ensures all AI work is consolidated.
